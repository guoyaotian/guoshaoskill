# 学会合作主题班会逐字稿

## 一、发现合作（对应课件第1页）

同学们，今天我们一起聊聊合作。两个人一起做事，怎样才能做得顺利？先想一个你和别人共同完成任务的例子。

```note
教师提示：请两名学生自愿分享，不把预设回答当作实际发言记录。
```

## 二、练习合作（对应课件第2页）

接下来，我们四人一组，把纸条按颜色分类。开始前，先用一句话说清楚自己的任务，再听听同伴是否需要帮助。

这个办法很好。

合作并不是每个人都做一样的事。我们可以**先商量分工**，再一起检查结果。如果出现不同意见，先听对方说完，再说明自己的理由。

```center
先倾听，再分工；遇到困难，一起想办法。
```

## 三、把合作带回生活（对应课件第3页）

今天你发现了什么？请选一个自己愿意尝试的合作做法，写在纸条上。下一次小组活动时，我们看看这些做法有没有帮助大家完成任务。

# 默认内容与验收规范

本文件是默认内容要求的唯一来源；用户要求和指定参考模板优先于默认值。

## 逐字稿

- 用温和、自然、适合目标年级的教师口语，按课堂环节组织。不要在正文读出“下一页”“PPT 第 X 页”等导航词或制作元数据。
- 默认二级标题标注来源页范围，使用 `一、情境导入（对应课件第1-3页）`；正文不含来源页提示。用户要求省略时全部省略。
- 默认最多 3500 字。导出器按正文中 Unicode 字母和数字逐字符统计：汉字每个计 1，英文单词按字母数计，数字按数字位数计；不计空白、标点、Markdown 标记、标题或 `note` 块。列表、表格和 `center` 块属于正文，纳入统计。该口径不等同于 Word 的“字数”功能；用户指定其他口径时需另外核算并说明，不能混用结果。
- 学生可能的回答写成“预设回答/可能回应”，不当作已经发生的课堂记录。教师提示、讨论时长或等待说明放 `note` 块，不混入直接口播。
- 补充案例和活动应符合年级、课时与主题，不虚构源课件中的视频、统计数据、人物言论或实践结果。

## 教案

默认依次使用以下十个二级标题。编号可以是 `1.` 或 `一、`，导出器按去除编号后的章节名校验；板书不依赖固定编号。

1. 教案基本信息
2. 学生心理特点分析
3. 教学重点与难点
4. 教学准备
5. 教学方法
6. 教学过程
7. 板书设计
8. 课后延伸
9. 教学反思与改进
10. 教学评价

“教案基本信息”分别成段写 `课题：`、`课型：`、`适用学段：`、`课时安排：`、`设计说明：`、`育人目标：`，每项有实际内容。目标应说明学生能识别什么、完成什么或如何表现，避免仅写“提高意识”。

“学生心理特点分析”结合年龄和活动需要表述一般教学考虑，不给具体学生作未经支持的心理判断。

“教学过程”使用中文编号三级标题，如 `一、情境导入（对应课件第1-3页）`。每环节写明教师组织、学生任务、预设回应或结果、教师总结；活动包含可执行步骤。默认不在标题内加分钟数，但起草时校验所有活动合计能落在课时内。

“板书设计”下用一个 `board` 围栏代码块表示整块板书，使用短行和清晰层级。兼容旧稿在该章节下使用 `text` 或无语言围栏；其他章节的普通围栏不被误判为板书。

“教学反思与改进”在未授课时写“课后反思要点”或待填写的观察项。只有用户提供真实授课记录时才写已发生的效果，不虚构“学生积极参与、目标圆满达成”。

“教学评价”与育人目标对应，包含可观察表现或简单判断标准；“课后延伸”要说明任务和完成方式。

## 人工验收

自动校验完成后仍需检查：

- 来源：所有章节顺序、关键知识和页码可回溯；疑点已处理，补充内容没有冒充课件原文。
- 一致性：课题、对象、目标、活动顺序和结论在两个 Word 中一致。允许小环节拆分，来源覆盖不得无解释地缺失。
- 课堂可用性：教师可以直接讲，学生知道要做什么；包含活动后的反馈；总时长合理。
- 目标与评价：目标具有可观察表现，评价能检测该表现，避免空泛模板化文字。
- 真实性：预设与实录分开，反思不虚构授课结果。
- 版面：逐页查看成品，确认标题层级、段落密度、分页、表格和板书适合打印。
- 文件：实际成品可打开，未覆盖或删除原有文件，实际输出路径与交付说明一致。

# 🏫 班会资料包

**提供一份班会课件，配套生成可直接讲的课堂逐字稿与结构完整的教案，分别保存为两个 Word 文件。**

它把读课件、梳理教学环节、起草配套文字、导出 Word 和检查文件的流程整理成可复用技能，减少“有课件，还要另写讲稿和教案”的重复工作。

## 🎯 适合谁？能解决什么问题？

| 使用者 | 使用场景 |
| --- | --- |
| 中小学班主任 | 给主题班会、常规教育、节气教育课件配套讲稿和教案 |
| 德育教师、教研人员 | 整理课堂环节、育人目标、板书与教学评价 |
| 教学资料整理者 | 将已有班会课件整理成格式一致的 Word 配套资料 |

默认处理一份课件。用户明确要求多份时，按课件逐份执行、分别保存，不把多个主题合并成一套材料。

## ✨ 核心功能

1. **基于课件起草配套材料**：由宿主 AI 阅读课件，梳理主题、页码和教学环节，再分别起草逐字稿与教案。
2. **面向真实课堂组织内容**：逐字稿以教师口语为主，教师提示与口播文字分开；教案说明教师组织、学生任务、反馈与评价。
3. **默认十章教案结构**：涵盖基本信息、学情、重难点、准备、方法、过程、板书、延伸、反思和评价。用户指定其他结构时可以调整。
4. **可检查的字数与页码**：导出器检查口播正文上限、页码范围和两份草稿的来源页覆盖是否一致；默认口播正文不超过3500字。
5. **Word 排版与导出**：默认 A4、真实标题层级、紧凑段距、整块边框板书，支持基本强调、列表与表格，减少短表格跨页拆分。
6. **参考教案样式**：可以参考用户提供的 DOCX 结构与风格；导出器可采样首节纸张、边距与四个命名样式，另支持 JSON 样式配置。
7. **导出完整性检查**：检查空稿、未闭合代码块、缺章等问题，并回读导出的段落与表格文字进行比对，避免无提示丢字。
8. **保护已有文件**：同名成品整组另存 `_v2`、`_v3` 等版本；只允许清理本次任务创建且可确认归属的临时文件。

内容理解、OCR、教学设计和事实核对由宿主 AI 及其可用工具完成；附带 Python 脚本负责已起草 Markdown 的校验与 Word 导出，不是独立的“PDF一键转教案”程序。

## 📥 需要提供什么？

**必需：** 一份可读取的班会课件，或当前电脑上可访问的完整文件路径。

| 材料或偏好 | 说明 |
| --- | --- |
| PDF / PPTX | 作为来源材料；需要宿主能阅读对应文档和关键图片 |
| 旧版 PPT | 若宿主不能读取，需要转换副本，或改提供 PDF/PPTX |
| 参考教案 DOCX | 可选，用来确定结构、字体、段距与板书风格 |
| 年级、课时 | 可选；材料未注明且会影响活动安排时应补充 |
| 字数、语气、页码 | 可选，例如“3000字以内”“适合四年级”“不要显示页码” |
| 输出目录、产物范围 | 可选；可以只要逐字稿，或只要教案 |

扫描件、图片型课件需要图像阅读或 OCR 能力。模糊文字、无法打开的视频或缺失材料应说明，不能凭空补成源课件内容。

## 📄 会得到什么？

默认生成两个可编辑的 `.docx` 文件，保存在源课件所在目录：

| 成品 | 默认内容 |
| --- | --- |
| `课题班会逐字稿.docx` | 教师口语正文、自然衔接、明确的教师提示、环节页码；口播正文默认3500字以内 |
| `课题班会教案设计.docx` | 十章教案、对应的教学过程、整块板书、课后延伸、反思要点与评价 |

文件名按实际课题确定。默认页码放在环节标题中，不作为口播内容；用户要求隐藏时两份一并隐藏。没有真实授课记录时，反思写成待观察或待填写项目，不虚构课堂效果。

默认十章依次为：教案基本信息、学生心理特点分析、教学重点与难点、教学准备、教学方法、教学过程、板书设计、课后延伸、教学反思与改进、教学评价。

## 💻 在哪里运行？

本包面向具备本地文件访问、文档阅读和 Python 执行能力的 **Codex**。它不是独立桌面软件，也不会自行在后台运行。用户在对话中调用技能，AI 负责阅读和写作，附带导出脚本在本地运行。

Python 导出器本身不发起网络请求。宿主 AI 如何处理上传材料，取决于所用服务及设置，不能把“本地导出”理解为整个 AI 工作流程离线。

本包未在 WorkBuddy、Claude 或其他宿主完成安装与端到端验证，因此不提供已验证兼容的承诺。

## 🚀 Codex 安装与首次使用

### 第一步：下载安装包

点击本页顶部的 **下载技能安装包**，得到 `class-meeting-packager.zip`。提供这个文件或其完整路径给 Codex，发送：

```text
请把这个 ZIP 里的 class-meeting-packager（班会资料包）安装到我的本地技能目录，保留 README、脚本、示例和参考规范。检查技能是否可识别，以及 Python 和 python-docx 是否可用；若已有同名技能，先检查版本差异再更新。
```

保持 ZIP 内 `class-meeting-packager/` 目录结构完整。安装后若当前对话尚未识别，重新打开对话并让助手检查技能路径；也可直接提供安装后的 `SKILL.md` 完整路径供读取。

### 第二步：提供一份课件并调用

普通使用者不需要手动运行脚本。在 Codex 中提供课件，发送：

```text
使用 $class-meeting-packager 处理我提供的班会课件。

输出两个独立 Word：
1. 课堂逐字稿，3500字以内。
2. 配套教案设计。

以课件内容为依据，环节标题保留对应页码。
保存到课件所在目录，检查内容、字数、页码和版面。
如果有未完成的检查，请明确说明。
```

也可以在指令中提供真实文件路径，例如 `D:\课件\学会合作.pdf`。示例路径仅作说明，不是随包附带的真实课件。

### 第三步：查看结果

检查助手给出的两个 Word 路径和字数，打开文件确认课堂内容适用。导出器的结构检查不能替代教师对知识、活动、年级与课时的判断。

## 💬 可直接复制的更多示例

**指定年级与课时：**

```text
使用 $class-meeting-packager 处理这份课件，适用于小学四年级，一课时40分钟。逐字稿口语自然，活动安排留出讨论与反馈时间。输出逐字稿和教案两个 Word。
```

**参考学校教案：**

```text
使用 $class-meeting-packager 处理这份课件。教案结构和格式参考我同时提供的 DOCX，不要复制参考文件中无关的教学内容。生成后检查实际版面，说明无法自动复刻的部分。
```

**只要逐字稿，并隐藏页码：**

```text
使用 $class-meeting-packager，本次只生成课堂逐字稿，3000字以内，不显示对应课件页码。保存为一个 Word 文件。
```

**明确批量范围：**

```text
使用 $class-meeting-packager，处理我指定文件夹内的全部 PDF 课件，不包含子文件夹。每份分别生成逐字稿和教案两个 Word，以实际课题命名；同名时另存版本。逐份报告成功、失败和未完成检查，不清空原目录。
```

批量由宿主逐份编排，导出器每次处理一套草稿；本包没有独立的目录扫描批处理命令。

## ✅ 字数和自动校验说明

口播正文按 **Unicode 字母和数字逐字符** 计数：每个汉字计1、英文字母逐个计数、数字逐位计数；不计空白、标点、Markdown格式标记、标题与教师提示 `note` 块。口号、列表和表格正文计入。因此，它与 Word 自带字数功能可能不同。

自动检查包括字数、标准章节与基本字段、非空正文、板书、页码有效范围、两份来源页覆盖一致性及导出文字回读。页码标签可能仍与实际内容不符，语义与事实必须另行核对。

详细输入写法、参数、自定义结构与样式配置见 [导出器使用说明](references/export-guide.md)；教学验收见 [默认内容规范](references/default-output-standard.md)。

## ❓ 常见问题与限制

| 问题 | 处理方式 |
| --- | --- |
| 找不到技能 | 核对名称与安装目录结构，提供实际 `SKILL.md` 路径让助手检查；不要把下载 ZIP 当成已经安装 |
| PDF或PPT读不了 | 检查宿主文档能力；旧版PPT可转换副本或改提供PDF/PPTX，看不清内容需说明 |
| 缺少 python-docx | 用实际执行脚本的同一个 Python 安装依赖，不要安装到另一个环境 |
| 超过3500字 | 压缩口播正文，或根据用户要求调整上限；不将正文伪装为教师提示逃避计数 |
| 页码检查失败 | 按源文件物理页序重新核对环节；若用户要求无页码，起草与参数同步修改 |
| 文件已存在 | 默认整组另存版本，不覆盖旧成品；实际路径以导出结果为准 |
| Markdown写法报错 | 使用文档规定的子集，支持基本强调、列表、简单表格和围栏块；不支持的结构应改写，不能丢掉内容 |
| 参考教案不完全一致 | 自动采样不含直接格式、复杂继承、主题、页眉页脚、分节或复杂表格；需人工配置和渲染适配，不承诺像素级复刻 |
| 结构检查通过，版面未验收 | 说明缺少渲染能力；打开 Word 逐页查看，不能仅凭脚本成功就声称版面合格 |

本技能不生成或修改幻灯片，不自动发布教学资料，不保证教学效果。长表格、超过一页的板书、复杂参考模板仍需实际版面调整。普通保存异常会清理脚本自己产生的暂存文件并尽力回滚；断电或进程强杀不保证多文件整体原子提交。

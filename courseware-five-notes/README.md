# 📚 课件转五篇笔记

**提供一份PDF课件，按五种角度生成可复制的中文笔记，每篇不超过600字。**

它把反复使用的课件阅读、内容提炼和笔记写作要求封装成一个技能，适合需要介绍课件、梳理教学内容、制作教育类社交媒体文案的人。

## 🎯 适合谁？能解决什么问题？

| 使用者 | 使用场景 |
| --- | --- |
| 教师、教研人员 | 介绍一份课件，梳理知识点、教学设计和使用重点 |
| 家长会组织者 | 将会议课件整理成全貌介绍、成长信息和家校配合建议 |
| 培训者 | 把培训材料整理成内容介绍、重点拆解和应用说明 |
| 教育内容创作者 | 基于真实课件准备小红书等平台的笔记草稿 |

默认围绕同一份课件写五篇，各有侧重，避免把同一段概览重复五遍。

## ✨ 核心功能

1. **完整阅读与页码梳理**：按PDF实际顺序识别主题和重点，对图表、图片内文字进行必要的视觉核对。
2. **五个角度分别写作**：为不同读者提供不同用途的内容，见下表。
3. **基于原文提炼**：保留数据的对象、单位和语境；年龄、年级、时长未注明时不擅自补出。
4. **区分事实与建议**：课件已有活动和规则按原文整理；额外的操作方法、材料或时间安排明确标为“建议”。
5. **清晰的笔记排版**：每篇独立标题，结合Markdown层级、emoji、加粗和分点，便于复制修改。
6. **篇数与字数检查**：附带Python脚本，检查五篇是否齐全、编号是否有序、正文是否为空、每篇是否超过600字。
7. **提示原文疑点**：遇到单位不匹配、数据矛盾、旧日期或模板残留，提示核对，不自行改成未经证实的内容。

## 📝 会输出哪五篇？

| 笔记角度 | 面向谁 | 主要内容 |
| --- | --- | --- |
| 📖 全貌版 | 想快速了解整份课件的人 | 主题简介、学习收获、按页码梳理重点、原文明确的适用信息 |
| 💡 教学亮点版 | 教师、教育工作者 | 有依据的教学或沟通设计亮点，以及其可能的价值 |
| 🔍 知识拆解版 | 备课、复习、整理资料的人 | 核心概念、关键信息、数据和案例 |
| 🎯 应用场景版 | 需要实际使用指导的人 | 按原文选择游戏、活动、练习、案例、操作或回看场景 |
| ✅ 使用建议版 | 教师、学生、家长、培训者等 | 使用步骤、重点页、难点、相关材料与节奏建议 |

家长会等非授课材料会相应调整为“会议全貌”“信息梳理”等表述。材料没有完整游戏规则时，不会凭空补出一套玩法。

## 📥 需要提供什么？

**必需：** 一份可以读取的PDF课件，或它在当前电脑上的完整文件路径。

**可选：** 目标读者、发布平台、语气偏好，例如“面向教师，适合小红书，口语化但不夸大”。

默认交付为对话中的Markdown正文。需要保存文件时，补充“请同时保存为Markdown文件”。扫描PDF或图片型课件还需要所用软件具备图像阅读能力。

## ✅ 字数是怎么检查的？

按保守口径计算每篇所有非空白字符，**包含标题、标点、数字、emoji及Markdown符号**，上限600。它与发布平台的计数方式可能略有不同。

普通用户不用手动运行脚本。需要自行检查时，准备只含五篇正文的UTF-8 Markdown文件，在技能目录执行：

```bash
python scripts/check_notes.py notes.md
```

每篇标题格式为 `# 📝 笔记1｜标题`，依次到笔记5。共同来源说明放在校验文件之外。脚本检查篇数、顺序、正文是否为空和长度，**不能替代事实核对**。

## 🧩 常见问题与能力边界

| 情况 | 怎么处理 |
| --- | --- |
| 找不到技能 | 核对技能名称；WorkBuddy确认已启用，Codex可新建对话后检查安装位置。 |
| ZIP导入失败 | 确认上传的是技能ZIP，而不是含多个文件的教程合集；保留报错文字用于排查。 |
| PDF乱码或读不出来 | 检查PDF/图像处理能力；看不清的页面需要说明，不能猜测。WorkBuddy可参考[官方排查说明](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/FAQ)。 |
| 缺少Python | 让助手检查可用运行环境；无法运行时应说明未完成自动校验。 |
| 文件不存在 | 使用当前电脑上的文件路径，或重新上传；另一台电脑的路径无法直接读取。 |
| 原文数据矛盾 | 标为待核对，不擅自选择一个数或推断趋势。 |

本技能聚焦课件转文字笔记：不制作或修改PPT，不自动发布到社交平台，也不保证“爆款”、阅读量或教学效果。默认处理一份课件；多份资料请明确处理范围。

更新日期：2026年9月11日

**安装一次，以后只需提供PDF课件，再发送一句指令。** 选择你正在使用的软件，按对应步骤操作即可。

## 1. 这个技能能做什么？

技能名称：`courseware-five-notes`（课件转五篇笔记）。

根据一份PDF课件，生成5篇不同角度的中文笔记：

| 笔记 | 侧重点 |
| --- | --- |
| 📖 全貌版 | 主题、学习收获、按页码梳理内容 |
| 💡 教学亮点版 | 教学方法、活动和呈现设计 |
| 🔍 知识拆解版 | 核心知识、数据、案例 |
| 🎯 应用场景版 | 如何用于讲解、活动、复习等 |
| ✅ 使用建议版 | 重点页、难点、材料与节奏建议 |

默认每篇不超过600字，配有标题、emoji和清晰排版。严格依据课件写作；额外提出的使用方法会标为“建议”。家长会、培训等材料会按实际类型调整措辞。

## 6. 遇到问题怎么办？

| 情况 | 处理方法 |
| --- | --- |
| WorkBuddy提示技能包解析失败 | 确认上传的是内层 `courseware-five-notes.zip`，而非教程合集；保留报错文字，交给助手定位。 |
| 提示找不到技能 | 核对名称 `courseware-five-notes`；WorkBuddy检查是否已启用，Codex可新建对话后让它检查安装位置。 |
| 提示文件不存在 | 确认PDF在当前电脑上，重新上传或复制完整路径。另一台电脑的路径不能直接使用。 |
| PDF读不出来、文字乱码 | 请助手检查文档处理工具；扫描或图片型PDF需逐页查看图片，不能只提取文本后猜测。 |
| WorkBuddy缺少文档能力 | 按官方建议选择支持文档/图片的模型，或安装文档处理类技能。[官方排查说明](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/FAQ) |
| 提示缺少Python | 让助手先检查是否有可用运行环境，并说明所需配置。无法运行脚本时，应明确说明未完成自动校验。 |
| 内容太长或角度重复 | 发送：“请按技能要求重新检查，五篇各有侧重，每篇含标题不超过600字，修改后重新校验。” |
| 原文数据矛盾或日期过期 | 要求标为待核对，不让助手自行补出或修正成未经证实的数据。 |

## 7. 分享给朋友需要发什么？

发送这份教程和 `courseware-five-notes.zip` 即可。朋友在自己的软件中安装，再提供自己的PDF课件。
